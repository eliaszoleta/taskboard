All Features

A complete reference of everything Achiever Board can do — from basic task management to team collaboration.

Kanban Board

Your tasks are organized across four columns that represent stages of work. Every task card shows the title, priority, due date, and assigned user at a glance. The board updates in real time — no page refresh needed.

📋
Four-stage pipeline

To Do → In Progress → Done, with an automatic Overdue column for tasks past their due date. Move tasks as work advances.

🔢
Live task counts

Each column header shows how many tasks are currently in that stage.

☁️
Cloud sync

All changes save to the cloud instantly. Pick up from any device.

📱
Responsive layout

Works on desktop, tablet, and mobile browsers without an app install.

Task Details

Click any task card to open the full task panel. Here you can view and edit everything about a task in one place.

✏️
Title & description

Give tasks a clear name and add as much context as you need in the description field.

📅
Due dates

Assign a deadline. Overdue tasks are automatically flagged in red so nothing slips through.

📎
File & link attachments

Attach images, documents, or paste URLs directly onto the task.

💬
Notes & comments Team

Leave notes on tasks for yourself or add comments for teammates to review.

Priority Levels

Every task gets a priority to help you focus on what matters most. Priority is visible directly on the card so you don't need to open a task to see it.

High Medium Low
  • High — urgent work that needs attention today
  • Medium — important but not blocking; work on it next
  • Low — nice to have; tackle when higher priorities are clear

Each column has a priority filter dropdown so you can focus on, say, only High priority In Progress tasks without hiding everything else.

Filters & Views

Filters let you slice your board without losing any data. Everything is still there — you're just narrowing the view.

🔺
Priority filter

Per-column dropdown to show only High, Medium, or Low tasks in that column.

📆
Date filter

Filter by Today, This Week, This Month, Next Week, Last Week, Overdue, or a custom date range — applied across all columns at once.

👤
User filter Team

Show only tasks assigned to a specific team member.

🧹
Clear filters

A single click clears all active filters and restores the full board view.

Team Collaboration Team

The Team Board adds multi-user features built for small groups working together on shared projects. Every feature below is included on every plan — free or paid.

🙋
Task assignment + instant notifications

Assign any task to a team member — they get notified immediately. Assigned tasks show the member's avatar on the card.

💬
Comments with real-time reply threads

Leave threaded comments directly on tasks. Teammates get notified the moment a comment is posted on their tasks.

🔔
Comment notifications on your tasks

Get notified whenever someone comments on a task assigned to you — so you never miss an update.

💬
1-on-1 direct messages

Send private direct messages to any teammate without leaving the board — no separate chat tool needed.

📢
Team announcement board

Admins can post announcements visible to the whole team. Keep important updates in one place with admin-controlled posting.

📋
Personal activity & notification feed

Each user has a personal sidebar feed showing tasks assigned to them and recent activity across the workspace.

👤
Admin controls — add & remove members

Workspace admins can add new team members, remove existing ones, and manage seat capacity from the settings panel.

🖼️
Profile avatars

Upload a profile photo to help teammates identify who's assigned to what at a glance.

All plans — including the free 2-user plan — include every feature listed above. Pricing is a flat team rate (not per person), and you can cancel anytime.

Data & Privacy

Achiever Board stores your data securely in Google Firebase with real-time sync. Your task data is never shared with third parties for advertising. See our Privacy Policy for full details.

  • Data encrypted in transit (HTTPS)
  • Firebase Realtime Database with security rules
  • No data stored in your browser — clearing cache won't lose your tasks
  • Delete your account and all data at any time from Profile Settings
